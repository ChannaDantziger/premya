## תוצרים שנוצרו בעקבות ההתכתבות

- `../אפיון.md` — מסמך האפיון המרכזי.
- `אפיון.docx` — גרסת Word בסיסית של האפיון.
- `ERD.md` — תרשים ומיפוי הישויות.
- `ARCHITECTURE.md` — ארכיטקטורת המערכת וצד הלקוח.
- `SCREEN-SKETCHES.md` — סקיצות של שלושת המסכים.
- `API.md` — תכנון API מרוכז.
- `SQL.md` — שאילתות SQL מרכזיות ואינדקסים.
- `DELIVERY-CHECKLIST.md` — בדיקת תוצרי הגשה.
- `AI-CONVERSATION-HISTORY.md` — היסטוריית ההתכתבות.
