# סקיצות מסכים

המסמך מתאר את שלושת המסכים המרכזיים שנדרשו במבחן. “תצוגה גראפית” במסמך המבחן מתייחסת לסקיצה של ממשק המשתמש; לא נדרש מסך של גרפים עסקיים.

## מסך 1 — ניהול שיטות פרמיה

```text
┌──────────────────────────────────────────────────────────┐
│ Premya                         [שיטה חדשה]               │
│ ניהול שיטות פרמיה                                        │
├──────────────────────────────────────────────────────────┤
│ מספר שיטה │ תיאור │ אחוז פרמיה │ תקופת חישוב │ פעולות    │
│ PM-001    │ ...   │ 12.5%      │ רבעון       │ עריכה     │
├──────────────────────────────────────────────────────────┤
│ [טופס הוספה/עריכה: מספר, תיאור, אחוז, תקופה] [שמירה]     │
└──────────────────────────────────────────────────────────┘
```

## מסך 2 — ניהול מדדים

```text
┌──────────────────────────────────────────────────────────┐
│ ניהול מדדים                         [מדד חדש]             │
│ שיטת פרמיה: [PM-001 ▼]                                      │
├──────────────────────────────────────────────────────────┤
│ שם │ תיאור │ סוג מקור │ מקור │ תדירות │ פעולות             │
│ עובדים │ ... │ Excel │ עובדים.xlsx │ רבעוני │ עריכה        │
├──────────────────────────────────────────────────────────┤
│ שדות המדד:                                                │
│ [שם שדה] [סוג נתון] [רלוונטי ✓] [סדר הצגה] [הוספה]        │
└──────────────────────────────────────────────────────────┘
```

## מסך 3 — קליטת נתונים וצפייה בנתונים

```text
┌──────────────────────────────────────────────────────────┐
│ קליטת נתונים למדד                                        │
│ שיטה [▼]  מדד [▼]  שנה [2026]  תקופה [רבעון 1 ▼]         │
│ קובץ Excel [בחירת קובץ]                     [קליטת קובץ] │
├──────────────────────────────────────────────────────────┤
│ תוצאת קליטה: הצלחה / כשל | רשומות: N | הודעה             │
├──────────────────────────────────────────────────────────┤
│ היסטוריית קליטות                                         │
│ מועד │ קובץ │ שנה │ תקופה │ סטטוס │ רשומות │ צפייה        │
├──────────────────────────────────────────────────────────┤
│ נתוני המדד                              [חיפוש] [סינון]   │
│ שדה 1 ↕ │ שדה 2 ↕ │ שדה 3 ↕                              │
│ ערך    │ ערך    │ ערך                                    │
│                         [עמוד קודם] 1 / N [עמוד הבא]      │
└──────────────────────────────────────────────────────────┘
```

## עקרונות התצוגה

- הטבלה במסך 3 נבנית באופן דינמי לפי השדות שנשמרו בגרסת הקובץ.
- ניתן להציג רק שדות שסומנו כרלוונטיים למדד.
- סינון, מיון ועימוד מבוצעים באמצעות ה־API כדי להתמודד עם כמות מידע גדולה.
- הודעות הקליטה כוללות הצלחה, מספר רשומות, שדות חסרים או סיבת כשל.
